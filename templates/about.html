Accessibility

Skip link, landmarks, keyboard-full forms, visible focus ring, system fonts at 16px+, green (#34f5a2) and cyan (#38e1ff) on near-black tested above 7:1 for body text. Terminal is a real input with label. No autoplay, no seizure-risk animation — one static gradient bar only. Issues welcome.

Images & copyright

No stock photos, no logos pulled from search. All visuals are hand-written CSS. Lesson text is original. If you spot a copied passage, file an issue and it gets rewritten or removed.

Risks we still carry

  • Teaching offense, even sandboxed, can be misused — mitigated by fictional-only targets, blocked commands, and conduct bans, not eliminated.
  • Simple handle login (no password) trades security for prototype speed — don't reuse a real password as a handle.
  • Scripted labs teach patterns, not live networks — graduates still need supervised practice before touching production.
